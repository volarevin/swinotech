# SwinoTech

SwinoTech is a PHP/MySQL piggery management system for tracking pigs, sows, sales, farm monitoring, reports, and IoT sensor data.

 Setup:
 
1. Start Apache and MySQL/MariaDB.
2. Create a database named `swinotech`.
3. Import swinotech.sql to phpMyAdmin.
4. Update database settings if needed in `includes/db.php`.
5. Open:

   `http://localhost/SwinoTech/login.php`
